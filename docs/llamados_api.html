Llamados a la API

Peticiones de prueba contra el despliegue en Render (https://disruption-guardrails.onrender.com), con tools mockeadas y el caso base del enunciado (reserva ABC123).

#PeticiónHTTP esperadoResultado
1 Evaluar ABC123 POSThttps://disruption-guardrails.onrender.com/v1/bookings/ABC123/disruption-assessment 200 HUMAN_REVIEW, motivo HUMAN_APPROVAL_REQUIRED (R5: viaja un menor).
2 Evaluar y ejecutar acciones POSThttps://disruption-guardrails.onrender.com/v1/bookings/ABC123/disruption-assessment?act=true 200 Crea el caso HC-4471 (cola DISRUPTION_L2, SLA 45 min) y la notificación NT-9912.
3 Confirmar O1 POSThttps://disruption-guardrails.onrender.com/v1/bookings/ABC123/rebooking-confirmations Body{"optionId":"O1"} 200 REJECTED APPROVAL_REQUIRED: con R5 la reprogramación la ejecuta un agente.
4 Confirmar O1 enviando un caseId como "aprobación" POSThttps://disruption-guardrails.onrender.com/v1/bookings/ABC123/rebooking-confirmations Body{"optionId":"O1","approval":{"caseId":"HC-4471"}} 200 REJECTED APPROVAL_REQUIRED: el cliente no puede auto-aprobarse (corrige el salto de aprobación).
5 Reserva inexistente POSThttps://disruption-guardrails.onrender.com/v1/bookings/ZZZ999/disruption-assessment 200 HUMAN_REVIEW TRIP_UNAVAILABLE: falla controlada, sin error 500.
6 Localizador inválido POSThttps://disruption-guardrails.onrender.com/v1/bookings/abc/disruption-assessment 400 INVALID_BOOKING_ID.
7 Pedir compensación POSThttps://disruption-guardrails.onrender.com/v1/bookings/ABC123/disruption-assessment Body{"compensationRequested":true} 200 Derechos R3 (reprogramar sin costo), R4 (compensación, requiere aprobación humana) y R5.
8 Confirmar O2 POSThttps://disruption-guardrails.onrender.com/v1/bookings/ABC123/rebooking-confirmations Body{"optionId":"O2"} 200 REJECTED OPTION_NOT_OFFERABLE: 1 asiento para 2 pasajeros y requiere pago.
Las peticiones con body llevan el header Content-Type: application/json. Ejemplo con curl:
curl -X POST https://disruption-guardrails.onrender.com/v1/bookings/ABC123/rebooking-confirmations -H 'content-type: application/json' -d '{"optionId":"O1"}'

El plan gratuito de Render apaga el servicio cuando está inactivo: la primera petición puede tardar unos 50 segundos.
Resultados verificados contra el despliegue en Render. Todos los endpoints son POST; abrir la URL base en el navegador responde 404.
